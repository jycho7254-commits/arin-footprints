# 김아린 성공기 🏆

김아린(2025.04.07생)의 성장 성공기 앨범 PWA — 우리 가족만의 비밀 공간.

## 🔗 링크

- **앱**: https://jycho7254-commits.github.io/arin-footprints/
- **가족 비밀번호**: `250407`

## ✨ 기능

| 탭 | 기능 |
|---|---|
| 📖 앨범 | 사진/동영상 타임라인 (날짜+메모+D+day 태그, 날짜 팝업) |
| 📸 기록 | 사진/동영상 업로드 (자동 리사이즈, 동영상 30MB) + 메모 |
| ✏️ 일기 | 사진 없는 짧은 기록 |
| 🗓️ 달력 | 사진 올린 날 썸네일, 출생일 💗 마킹 (2025.04.07) |

- 👥 **부모 실시간 공유** — 서버 저장, 양방향 동기화
- 🔗 **카톡 공유** — Web Share API
- 📱 **PWA** — 홈 화면 설치 앱
- 🗑️ 삭제 — 카드/일기별, 서버+로컬 동시
- 🏆 **D+day** — 현재 D+500대, "아린이랑 ○일" 표기 (로컬 자정 기준)
